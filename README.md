# Flask CRUD REST API

A simple CRUD REST API built using Python Flask, SQLAlchemy, PostgreSQL, Docker, and Postman.

## 📌 Project Overview

This project demonstrates how to build and test a RESTful API that performs CRUD operations on users.

CRUD stands for:

- Create
- Read
- Update
- Delete

The application uses Flask to create the REST API, SQLAlchemy to interact with the database, PostgreSQL as the database, Docker for containerization, and Postman for API testing.

## 🛠️ Technologies Used

- Python
- Flask
- Flask-SQLAlchemy
- PostgreSQL
- Docker
- Docker Compose
- Postman
- Git
- GitHub
